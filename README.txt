Запуск локально: откройте index.html в браузере.
Публикация: загрузите содержимое папки CRM_HTML в корень GitHub-репозитория и включите Settings → Pages → Deploy from a branch → main / root.

ВАЖНО:
Это статическая демонстрационная версия для GitHub Pages. PHP и серверная база данных здесь не используются. Записи добавляются, редактируются и удаляются в интерфейсе, а затем сохраняются в localStorage браузера на текущем устройстве. Авторизация демонстрационная и не является защитой данных. Не используйте для реальных персональных или коммерческих данных.
Для чистого старта: Администрирование → Сбросить демо-данные (либо очистить localStorage сайта).
